SQL Injection

Learn how improper handling of user input can allow attackers to manipulate database queries.

DIFFICULTY BEGINNER
TYPE WEB SECURITY
01 OBJECTIVE

Understand the vulnerability

SQL Injection occurs when untrusted user input is directly included in a database query. An attacker may manipulate the query and change how the database processes the request.

HINT

Look closely at how the username and password values are used to build the database query. Think about what happens when the input changes the structure of the query.
